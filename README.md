## 🔥 Featured Projects

### 🔐 AI Security Gateway

An **OpenAI-compatible AI Security Gateway** designed to secure applications using cloud-based LLMs.

The system combines security scanning with reversible PII anonymization and secure LLM request handling.

**Focus:** LLM Security · PII Protection · Anonymization · Prompt Injection · Secure APIs · Multi-provider LLMs

**Technologies:** Python · FastAPI · React · TypeScript · SQLAlchemy · Docker

---

### ♿ WheelMatch

A web platform designed to connect **patients, clinicians, and wheelchair vendors** through a structured wheelchair catalog and recommendation system.

The platform provides dedicated interfaces and workflows for different users involved in wheelchair selection and management.

**Focus:** Full-Stack Development · Recommendation Systems · User Management · Healthcare Applications

**Technologies:** React · JavaScript · Bootstrap · REST APIs

---

### 🚦 TrafficRL

A **reinforcement learning-based traffic signal control system** developed using **SUMO (Simulation of Urban Mobility)**.

The project focuses on optimizing traffic flow in **single and multi-intersection road networks** by replacing fixed-time traffic lights with adaptive decision-making agents.

The system simulates urban traffic scenarios and evaluates reinforcement learning approaches such as:

* 🧠 **Q-Learning**
* 🤖 **Deep Q-Networks (DQN)**
* 🚦 Adaptive traffic signal control
* 📊 Traffic flow optimization
* 🛣️ Single and multi-intersection scenarios

The objective is to **reduce congestion and improve traffic efficiency** through intelligent decision-making.

**Technologies:** Python · Reinforcement Learning · Q-Learning · DQN · SUMO

---

### 💼 Workify

**Workify** is a full-stack freelance marketplace platform connecting freelancers with clients.

The platform supports multiple user roles and complete marketplace workflows:

* 👨‍💻 **Freelancers** — Create gigs, respond to offers, and manage hires with milestones
* 🧑‍💼 **Clients** — Post job offers, browse freelancer gigs, and hire talent
* 🛡️ **Admins** — Manage users, moderate content, and oversee withdrawals

The project focuses on building a complete marketplace ecosystem with user management, offers, hiring workflows, milestones, and administrative operations.

**Focus:** Full-Stack Development · Marketplace Architecture · User Management · Offers & Hiring · Milestones · Administration
